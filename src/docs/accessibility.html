:focus-visible outlines

Jellyfish includes clear focus highlighting of buttons, anchors, and inputs to aid users navigating a website via keyboard. To preserve design aesthetics these styles will not be applied when a user is navigating with a mouse - with the exception of input fields which, by specification, should inherit :focus-visible when active. Increase font size globally

Give any button a data-font-size of smaller, default, larger or largest. The bundled accessibility.js handles the click by delegation (no inline handler, CSP‑safe), adds the matching .font-size-* class to <html> (default = none) — a relative multiplier on --jf-root-font-size, which is read on <html>, so the whole rem‑based type scale grows or shrinks with it — and stores the choice in localStorage under jf-font-size. The active button gets aria-pressed="true". window.setRootFontSize('larger') is exposed for script callers.

These are preference levels, not scale steps — deliberately named smaller…largest rather than reusing the $type-scale keys.

Restoring the stored preference runs on DOMContentLoaded; add the inline snippet to your <head> if you want it applied before first paint (no flash).
