Design Tokens[ Variable Reference ]

Every non-colour design axis is a thin semantic scale of CSS custom properties, each with a matching get-*() Sass accessor. The value tables live on the Variables page and the accessors on Mixins — this page shows them rendered, and the last section demonstrates what happens when you retune a token.

Reference a token from CSS with its full --jf-* name, or from SCSS with the accessor: padding: get-space(md);, border-radius: get-radius(lg);, box-shadow: get-shadow(md);.

Extending a scale. Every scale ($space-scale, $radius-scale, $leading-scale, $duration-scale, $ease-scale) uses the empty-map + merge pattern — your map is merged over the defaults. Set one before importing Jellyfish: a matching key overwrites ($radius-scale: ("md": 20px) makes --jf-radius-md 20px), a new key appends (("xxl": 40px) adds --jf-radius-xxl, resolvable as get-radius(xxl)). Everything you don't mention keeps its default. Setting it after the import is too late — the !default has already fired.

Spacing --jf-space-*

A t-shirt scale pointing at $sizing-system steps. --jf-flow is the block-flow rhythm (bottom margin between block elements) — $flow-step picks which step it uses, md by default. The raw $sizing-system map stays Sass-only — use get-size() for build-time maths, these tokens for anything themeable.

--jf-space-2xs4px
--jf-space-xs8px
--jf-space-sm16px
--jf-space-md24px — --jf-flow default
--jf-space-lg48px
--jf-space-xl96px
--jf-space-2xl128px
--jf-space-3xl192px

Border radius --jf-radius-*

The scale is the semantic layer. Component defaults map onto it — retune the whole framework's corners from the $radius-scale map.

none xs sm md lg xl 2xl full

Border width --jf-border-width

Two widths only. Naming mirrors the colour role ladder.

--jf-border-width — 1px --jf-border-width-strong — 2px

Elevation --jf-shadow-*

Box-shadows that mix --jf-shadow-color toward transparent at each step's alpha. Reference with get-shadow() or the token name. Geometry in $shadow-scale; hue in $shadow-color / --jf-shadow-color.

xs sm md lg xl

Motion --jf-transition

Hover the boxes. Each declares its own transition from the motion tokens; the OS "reduce motion" setting zeroes the durations and stops all of them.

base fast slow slow · ease-out slow · ease-in-out slow · spring

Retuning tokens

The wrapper below sets four tokens to non-default values inline. Anything inside that reads them re-resolves with no other change — a single scope override cascades. This section is the permanent visual check for the token cascade: if a swatch stops responding, something's regressed.

radius-lg → 1px border-width → 4px padding: --jf-space-md → 6px --jf-shadow-lg full override

Components: the framework's own $*-border-radius, border widths and element spacing move onto these tokens in Tranche 2 — after that, a wrapper override like this restyles a .card / .button / .callout the same way.
