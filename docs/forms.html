Jellyfish applies styling to all standard form elements to make them look great without hassle or additional classes.

Use the $form-accent-color variable to apply accent color to form elements.

Textareas use field-sizing: content, so where the browser supports it they grow to fit what's typed (the rows attribute sets the starting height). Elsewhere they stay at rows height and scroll, as before.

<select> now sizes to its widest <option> (width: fit-content) and is capped at max-width: 100% so a long option can't overflow its container. The old 300px / 60% default is gone. Inside a .col or .form-row it fills the column as before; set width yourself for a fixed size.

Working with checkboxes and radio buttons

A set of related checkboxes or radio buttons that answers one question is a group: wrap it in a <fieldset> with a <legend> naming the choice. Each control keeps its own <label>; the <legend> is what a screen reader announces for the group as a whole.

For a single control, or to group controls for spacing only (no group label), use .form-group instead.

Add .form-group-inline to lay the controls out inline rather than stacked. It works on a <fieldset> too — the <legend> stays on its own line above the row.

Any set of related controls can sit in a <fieldset> — the radio group above is the common case, but it also suits a larger block such as a sign-in or address section. Add a <legend> whenever the group needs a name; Jellyfish styles it to sit across the top border.

Validation states

Once a field has been interacted with, :user-invalid turns its border error — no class or JavaScript. Unlike :invalid it won't flag empty required fields on load. Only the invalid state is styled; there's no green :user-valid treatment.

Helper text like this uses .form-hint (muted). Type something that isn't an email and blur the field to see the invalid state.

For a server- or script-rendered error, set aria-invalid="true" on the field — the framework styles it identically to :user-invalid — and point aria-describedby at the message. Style the message with .form-error (error colour, semibold). The ARIA is what a screen reader needs; :user-invalid on its own isn't announced. Add role="alert" to a message inserted after load.

Recolouring the select chevron

The select chevron is drawn from $select-chevron-icon-svg, coloured by $select-chevron-color. Custom properties can't be used inside an embedded SVG data-URI, so to recolour the chevron for a given context (eg. a dark background), use the select-bg() mixin rather than overriding a CSS variable directly. 

    
      .my-dark-section select {
        @include select-bg(#fff);
      }

To change the chevron's shape entirely, override $select-chevron-icon-svg before Jellyfish is imported — keep the {{color}} token in your replacement SVG so select-bg() can still substitute the colour.

The chevron is a background image, so in forced-colors modes (Windows High Contrast) it keeps rendering but in its fixed colour rather than a palette one. The <select>'s border and text take system colours as normal.
